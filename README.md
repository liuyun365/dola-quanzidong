# 提示词管理器（Dola 视频生成）

一个本地运行的提示词工作台 + 自研 Dola（Dreamina Seedance 2.5）批量视频生成引擎。

- **左侧**：资源管理器式树状浏览本地文件夹 / 文件（默认空，用工具栏「添加文件夹 / 添加文件」加入，删除只删记录不删实体）。
- **右侧**：以原生文档形式打开提示词文件，自动识别 `###镜头n` 分镜；每个分镜段首段尾各一个「复制」按钮一键复制整段；正文可直接编辑，`Ctrl+S` 覆盖保存原文件。
- **生成**：资产关联 → 每镜单独生成 / 批量生成 / 失败镜头重试；自建账号号池 + CDP 真实 Edge 驱动 Dola 生成无水印视频。

## 二、安装步骤

1. **安装依赖**：按上表装好 Python、Node.js、Edge、Clash 代理。
2. **获取代码**：将本项目（`提示词管理器` 目录）放到本机任意位置，例如 `F:\提示词管理器`。
3. **配置代理**：启动 Clash，确保有一个可访问 Dola 的节点（如南亚 / 日本），并让系统 HTTP 代理生效在 `http://127.0.0.1:7897`（默认端口，可在界面「代理」输入框修改）。
4. **启动**：双击 **`启动提示词管理器.bat`**：
   - 自动启动后端（Python `app.py`，端口 8848，见 `port.txt`）；
   - 自动用默认浏览器打开 `http://127.0.0.1:8848/`；
   - 若已有一个后端在运行，则直接打开页面（不会重复启动）。
5. **首次使用**：
   - 用工具栏「添加文件夹 / 添加文件」把存放提示词剧本的目录加进来；
   - 点击左侧文件，右侧打开并自动识别分镜；
   - 若用到生成，先做「资产关联」（配置资产库 + 匹配参考图），再批量 / 单镜生成。

## 三、号池（Dola 账号池）怎么准备

生成引擎需要 **Dola 账号号池**，机制如下：

- 号池存于 `dola_engine\state\accounts.sqlite3`，账号凭据用 Windows DPAPI 加密（`dola_engine\state\pool\*.dpapi`），**不会进入 Git**。
- **自动补给**：任务运行中可用号 <5 时自动取号注册到上限 20；达到 20 停止（手动导入不受上限限制）。
- **每号默认 1 次**：生成视频下载完成后，该账号转入「已生成」归档（标记剧集 + 镜号）。
- **失败即弃**：登录失败 / 无 30 秒能力 / 内容被拒（肖像、版权等）一律删号换新，最多重试 5 次（未登录、无 30 秒不占失败次数）。
- **取号**：可在 `dola_engine` 目录执行 `python pool.py stats` 查看号池统计。

**需要你准备的**：可用邮箱（或临时邮箱服务）来注册账号。可手动把已有账号导入号池，或配置好邮箱服务后由引擎自动注册。

> 账号注册 / 批量使用行为请遵守 Dola 平台服务条款与当地法律法规，风险自负。本仓库不提供任何绕过验证、指纹伪装或滥用工具。

## 五、生成流程 & 规则

1. **串行提交**：逐镜提交（提交确认「本次使用 Dreamina Seedance 2.5 生成…」即通过，立即进入下一镜）；提交后后台预开下一窗口并登录好。
2. **并发收片**：全部提交后并发等待出片 → 经哆啦助手解析无水印 → 下载 → 归档。
3. **失败自动处理**：被拒 / 平台错误 / 异常 → 换号重试（≤5）；收片无水印失败先多重试嗅探，仍失败则下载**原片**（文件名前缀 `原片_`）并保留窗口待你查看，**不重新生成**。
4. **长效收片记录**：收片状态写入 `state/pending_shots.json`（不入库），切换剧本 / 刷新 / 重启后仍可查看、可恢复。
5. **视频命名**：`集数_镜号_序号.mp4`，如 `第001集_镜3_1.mp4`。
6. **进度面板**：实时显示当前动作；可停止；任务完成后可「重试失败镜头」，每镜也可单独重新生成（无论成败）。

## 六、常见问题

- **页面打不开 / 端口被占**：关闭占用 8848 的进程后重新双击启动器；或改 `port.txt`。
- **生成总失败 / 窗口卡加载**：多为代理节点不可达 Dola。换一个可用节点，确认 `http://127.0.0.1:7897` 生效。
- **账号"无 30 秒能力"**：该账号仅支持 10 秒，引擎会自动换号（不占失败次数）。
- **内容被拒（肖像 / 版权等）**：参考图或提示词触发审核，引擎会换号重试；多次仍拒则判失败，可在进度面板「重试失败镜头」。
- **收片记录显示"待查看"（原片）**：无水印暂未解析到，已下载原片并保留窗口，可手动在页面查看 / 重新解析。
